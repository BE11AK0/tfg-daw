# Bellaudio (TFG DAW)

DAW desarrollado con React y Web Audio API, empaquetado como aplicación de escritorio con Tauri y Rust.

- **Versión web:** https://tfg-daw-sepia.vercel.app
- **Descarga de escritorio (Windows):** https://github.com/BE11AK0/tfg-daw/releases

## Descargar e instalar en Windows

1. Entra en la sección **Releases** del repositorio y descarga el instalador más reciente (`.exe` de NSIS o `.msi`).
2. Ejecuta el archivo descargado y sigue los pasos del asistente de instalación.
3. Si **Windows SmartScreen** muestra un aviso por falta de firma digital, haz clic en **Más información** y luego en **Ejecutar de todas formas**.
4. Abre **Bellaudio** desde el acceso directo del escritorio o el menú Inicio.
